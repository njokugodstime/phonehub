# PhoneHub

A full-stack e-commerce web application for browsing and purchasing phones and accessories, built with plain PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Product catalog with category filtering and search
- Product detail pages with stock tracking
- Shopping cart using PHP sessions
- Checkout flow with order and order-item creation (database transactions)
- User registration, login, and authentication
- Admin panel: dashboard with stats, add/edit/delete products with image uploads, manage order statuses

## Tech Stack
- PHP (procedural, PDO for database access)
- MySQL
- HTML, CSS, JavaScript
- Git/GitHub for version control (feature branches, pull requests)

## Setup
1. Clone the repo
2. Import `database/schema.sql` into MySQL
3. Update `includes/db.php` with your database credentials
4. Point Apache to the `public/` folder
